SkyCAIR is a modular Live OS. It runs directly from USB,
SSD, NVMe, or any storage without erasing your existing data.
It can also be permanently installed to a partition.

Supported filesystems: ext2, ext3, ext4, FAT, exFAT, NTFS, XFS
Required CPU: SSE4.2 or newer (Intel/AMD from ~2010+)
Minimum RAM: 1 GB  (2 GB recommended for Copy To RAM mode)

NOTE: Do NOT use Rufus, Etcher, or Balena to write this ISO.
They make the media read-only and break the save system.
Use skycair-installer-for-linux.run or
skycair-installer-for-windows.exe instead.


================================================
  STEP 1 -- CHOOSE YOUR STORAGE
================================================

Best performance:  SSD or NVMe (internal or external)
Portability:       USB 3.0 drive (8 GB minimum)
Testing:           Any partition with free space

SkyCAIR will not erase existing data. It only adds
/boot, /EFI, and /skycair folders to your storage.


================================================
  STEP 2 -- COPY FILES TO YOUR STORAGE
================================================

EFI Systems (modern hardware -- recommended):
  1. Ensure the first partition is FAT32
  2. Copy /boot and /EFI folders to the FAT32 partition
  3. Copy /skycair to FAT32 or to a second partition

Legacy/BIOS Systems:
  1. Copy /boot and /skycair to your desired partition

Then continue to Step 3.


================================================
  STEP 3 -- RUN THE INSTALLER
================================================

From Windows:
  1. Open the /boot folder you just copied
  2. Run: skycair-installer-for-windows.exe
  3. Follow the prompts

From Linux:
  1. Ensure zstd is installed on your system
  2. Open a terminal in the /boot folder
  3. Run: sh skycair-installer-for-linux.run
  4. Follow the prompts

Reboot and select your storage device in BIOS/UEFI.


================================================
  STEP 4 -- BOOT MENU OPTIONS
================================================

  Graphics Mode       Default. COSMIC desktop. Changes saved
                      to storage on shutdown (EXIT mode).

  Persistent 16GB     Saves ALL changes in real time to a
                      16 GB file on your storage device.
                      See "Save Data" section below.

  Install to Disk     Boots the desktop and opens GParted
                      so you can prepare a target partition,
                      then run the installer.

  Copy To RAM         Loads all modules into RAM at boot.
                      Fastest mode. Requires 2 GB+ RAM.
                      Storage can be removed after startup.

  Always Fresh        No changes saved. Clean every boot.
                      Good for testing.

  Safe Mode           Basic drivers only, no KMS/GPU.
                      Use if the display fails to start.

  Text Mode           CLI only, no desktop loaded.

Default login:  guest / guest
Root login:     root / toor


================================================
  SAVE DATA -- PERSISTENT 16 GB SAVE FILE
================================================

The Persistent 16GB boot option uses a file called
skycair-save.dat stored in your /skycair folder.
Everything you install, configure, or create is saved
inside it and survives reboots.

To CREATE the 16 GB save file (run once as root):

  Option A -- Use the helper script:
    sh /boot/skycair-scripts/create-save-data.sh

  Option B -- Manually:
    dd if=/dev/zero of=/skycair/skycair-save.dat bs=1M count=16384
    mkfs.ext4 -F /skycair/skycair-save.dat

After creating it, select "Persistent 16GB" at boot.

Custom sizes (change count):
    8 GB  = count=8192
    16 GB = count=16384  (default)
    32 GB = count=32768
    64 GB = count=65536

Custom location -- add this SkyLEGO parameter at boot:
    changes=/path/to/yourfile.dat

NOTE: Save files require a Linux filesystem (ext4 or XFS).
FAT and NTFS partitions cannot host .dat save files.


================================================
  INSTALLING TO A PERMANENT PARTITION
================================================

  1. Boot "Install to Disk" -- GParted opens automatically
  2. Use GParted to create/format your target partition
     (ext4 recommended, 20 GB minimum, 60 GB+ ideal)
  3. Note your partition (e.g. /dev/sda2 or /dev/nvme0n1p2)
  4. Mount it and copy /boot, /EFI, /skycair to it
  5. In /boot, run: sh skycair-installer-for-linux.run
  6. Set correct ownership:
       chown -R guest:users /mnt/yourpartition/skycair
  7. Reboot and select your new partition

On ext4/XFS, SkyCAIR auto-saves all changes on shutdown.
No .dat file needed for permanent installs.

================================================
  PERFORMANCE TIPS
================================================

  SSD or NVMe gives the best experience -- faster module
  loads and near-instant save/restore on shutdown.

  Copy To RAM is the fastest mode. All modules load once
  at boot; after that the system runs 100% in memory.
  Ideal for presentations or privacy-sensitive sessions.

  Persistent 16GB on an SSD is the best everyday setup:
  real-time saves, fast reads, your data survives reboots.

  The kernel is compiled with PREEMPT_FULL and HZ=1000 for
  low-latency desktop, audio, and gaming performance.

  Vulkan and Intel VA-API are enabled by default for Intel
  and AMD GPUs. For NVIDIA, install the driver from the
  App Store after first boot.

  Enable compressed swap (great for low-RAM machines):
  Add  zram=33%  to /skycair/skycair.cfg


================================================
  TROUBLESHOOTING
================================================

  Display won't start?
    Select "Safe Mode" at the boot menu (nomodeset).
    Install the correct GPU driver from the App Store.

  No network?
    Run:  nmtui   (terminal network configuration)

  No sound?
    Run:  pavucontrol   (volume and device manager)

  Boot hangs on slow USB?
    Add  delay=5  to boot options -- gives the USB
    extra time to initialize before mounting.

  Changes not saving on Linux filesystem?
    Run as root:  chown -R guest:users /skycair

  Changes not saving on FAT/NTFS?
    Use a .dat save file (see Save Data section above)
    or boot with:  changes=EXIT:/skycair

  Save changes immediately without rebooting?
    Run as root:  /opt/skycair-scripts/dump-session

  Boot into root recovery?
    Add at boot prompt:  login=root


================================================
  CHEATCODES -- QUICK REFERENCE
================================================

Add at boot prompt (Tab key) or save permanently in
/skycair/skycair.cfg (one per line, no leading spaces):

  changes=/skycair/myfile.dat   Use specific save file
  changes=EXIT:/skycair         RAM save, flush on exit
  copy2ram                      Load all modules to RAM
  rammod=003                    Load only module 003 to RAM
  zram=33%                      Enable compressed swap
  login=root                    Auto-login as root
  timezone=America/Chicago      Set timezone
  kmap=us                       Set keyboard layout
  volume=75                     Set master volume (0-100)
  nonetwork                     Disable auto network
  nobluetooth                   Disable Bluetooth
  vgadetect                     Auto-load NVIDIA driver
  nomodeset                     Disable GPU kernel mode
  delay=5                       Wait 5s before mounting
  baseonly                      Load base modules only
  norootcopy                    Skip rootcopy directory

Full reference: /boot/docs/skylego.txt
