 Press [Tab] to edit boot options. Press [Enter] to boot.
 Default credentials:  guest / guest   |   root / toor


 -Graphics Mode-  (DEFAULT)
 Best for most users. Boots the COSMIC desktop. Changes are
 saved to your storage device on shutdown (EXIT mode).


 -Persistent 16GB-
 Uses a 16GB save file (skycair/skycair-save.dat) on your
 storage device. Run create-save-data.sh first to create it.
 Changes are written continuously to the save file.


 -Install to Disk-
 Boots the desktop and launches GParted so you can prepare
 your target partition. Then run the SkyCAIR installer from
 the /boot folder to make the partition bootable.


 -Copy To RAM-
 Copies all modules into RAM at boot. Requires 2GB+ RAM.
 Slower to start but runs at maximum speed once loaded.
 Safe to remove the boot media after startup.


 -Always Fresh-
 Boots clean every time with no changes saved. Useful for
 testing or when troubleshooting issues.


 -Safe Mode-
 Boots in text mode with basic drivers only. No KMS/GPU.
 Use this if the display fails to start normally.


 -Text Mode / Text Mode Fresh-
 CLI only. No desktop environment is loaded.
